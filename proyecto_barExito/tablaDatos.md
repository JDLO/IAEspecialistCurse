| Dimensión de Datos | Variable Específica | Tipo de Dato | Dónde conseguir la información |
| :--- | :--- | :--- | :--- |
| **1. Financieros y Viabilidad** | **Inversión inicial (CapEx)** | Numérico continuo (€) | Presupuestos de reforma, licencias y equipamiento de proveedores; bases de datos de traspasos de locales. |
| | **Fondo de maniobra (Colchón)** | Numérico (Meses) | Plan de negocio del emprendedor o estimación de reservas de tesorería iniciales. |
| | **Punto de equilibrio (*Break-even*)** | Numérico (Clientes/mes) | Cálculos contables proyectados o registros históricos de bares similares. |
| | **Food & Labor Cost teórico** | Porcentaje (%) | Estandarizaciones de recetas de hostelería, guías del sector (ej. asociaciones de hostelería locales) o escandallos. |
| **2. Localización y Entorno** | **Tráfico peatonal estimado** | Numérico o Categórico (Alto/Medio/Bajo) | Herramientas de geomarketing, datos abiertos de ayuntamientos (afluencia en calles comerciales) o conteo manual de prueba. |
| | **Densidad de competencia** | Numérico (Nº de locales en 500m) | Google Maps API, Google Places, TripAdvisor o censos comerciales de los ayuntamientos. |
| | **Demografía del área** | Categórico / Numérico | INE (Instituto Nacional de Estadística) o equivalentes locales, padrón municipal por barrios. |
| | **Visibilidad y tipo de calle** | Categórico (Esquina, calle principal, callejón) | Portales inmobiliarios (Idealista, Fotocasa) o inspección visual (*Google Street View*). |
| **3. Concepto y Operativa** | **Modelo de negocio** | Categórico (Cafetería, Tasca, Pub, etc.) | Clasificación interna basada en la licencia de actividad y oferta gastronómica. |
| | **Aforo y Terraza** | Numérico / Binario (Sí/No) | Licencias de apertura otorgadas por el ayuntamiento o datos de superficie del local. |
| | **Ticket medio proyectado** | Numérico (€) | Cartas de precios de la competencia directa en la misma zona geográfica. |
| **4. Perfil del Gestor** | **Experiencia previa en hostelería** | Binario o Categórico (0 = Ninguna, 1 = Experto) | Entrevistas previas con el emprendedor, formularios de incubadoras de negocios o registros de autónomos. |
| **5. Macroeconómicos** | **Evolución de costes energéticos/inflación** | Numérico (%) | Índices de precios al consumo (IPC) y boletines de tarifas eléctricas/gas de los años de apertura. |
