### 1. [Orange](https://orangedatamining.com/) 🍊
Programa informático de código abierto enfocado en el análisis de datos, la visualización de información y el aprendizaje automático (*machine learning*) mediante programación visual.

* 📂 **Directorio:** [./orange](./orange)

---

### 2. [Python (Basics)](https://www.python.org/) 🐍
Lenguaje de programación de código abierto, interpretado y de alto nivel, creado por Guido van Rossum en 1991. Está diseñado con una sintaxis limpia y legible que se asemeja al idioma inglés, utilizando sangrías (*indentación*) en lugar de llaves para estructurar el bloque de código.

* 📂 **Directorio:** [./pythonBasics](./pythonBasics)

---

### 3. [NumPy](https://numpy.org/es/) 📐
Biblioteca fundamental para el lenguaje de programación Python, diseñada para realizar computación científica, manejo de matrices y análisis de datos de alta velocidad.

* 📂 **Directorio:** [./numpy](./numpy)

---

### 4. [Matplotlib](https://matplotlib.org/) 📊
Biblioteca de código abierto para Python orientada a la creación de visualizaciones de datos en dos y tres dimensiones (gráficas de líneas, barras, dispersión, histogramas, entre otras).

* 📂 **Directorio:** [./matplotlib](./matplotlib)
